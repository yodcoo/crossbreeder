RUCKUS One

连接你的 RUCKUS One 租户，可以把 AP 地址列表直接拉进「目标设备」，也可以在任务中尝试每台 AP 每日轮换的 CLI 密码。
在 RUCKUS One 的「管理 → 账户管理 → 设置 → 应用令牌」处创建客户端 ID 和密钥，租户 ID 在同一页面。
RUCKUS One 会为每台 AP 设置不同的 CLI 密码并每日轮换。勾选后，程序会先试该地址的当前密码，再试「登录凭据」里填的密码。
